# REQ-001 : Connexion administrateur

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un administrateur peut se connecter avec des identifiants valides.

## Critères d'acceptation
1. Avec `admin` / `password`, la connexion réussit et l'accès à l'espace admin est donné.
2. Avec un mauvais mot de passe, la connexion est refusée et un message d'erreur s'affiche.
3. Avec des champs vides, la connexion est refusée.
