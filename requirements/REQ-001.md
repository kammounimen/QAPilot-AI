# REQ-001 : Connexion administrateur

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un administrateur peut se connecter avec des identifiants valides.

## Critères d'acceptation
1. Avec admin / password, la connexion réussit et l'espace admin est accessible.
2. Avec un mauvais mot de passe, la connexion est refusée et une erreur s'affiche.
3. Avec des champs vides, la connexion est refusée.
