# REQ-002 : Liste des chambres

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un visiteur voit la liste des chambres disponibles sur la page d'accueil.

## Critères d'acceptation
1. Chaque chambre affiche au moins son type et son prix.
2. La liste correspond aux chambres renvoyées par l'API.
3. Chaque chambre propose un bouton de réservation.
