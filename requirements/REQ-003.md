# REQ-003 : Création d'une chambre

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un administrateur connecté peut créer une chambre.

## Critères d'acceptation
1. Avec un numéro, un type, un prix et une accessibilité valides, la chambre est créée.
2. La nouvelle chambre apparaît dans la liste admin et sur la page d'accueil.
3. Avec un prix invalide ou un numéro vide, la création est refusée avec un message d'erreur.
