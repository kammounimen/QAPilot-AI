# REQ-004 : Modification d'une chambre

- **Priorité** : Moyenne
- **Couche** : API + UI

## Description
Un administrateur connecté peut modifier une chambre existante.

## Critères d'acceptation
1. La modification du prix ou du type est enregistrée.
2. La modification est visible sur la page d'accueil.
3. Une modification avec des données invalides est refusée.
