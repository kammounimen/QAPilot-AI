# REQ-005 : Suppression d'une chambre

- **Priorité** : Moyenne
- **Couche** : API + UI

## Description
Un administrateur connecté peut supprimer une chambre.

## Critères d'acceptation
1. La chambre supprimée disparaît de la liste admin et de la page d'accueil.
2. Supprimer une chambre inexistante ne provoque pas d'erreur serveur (pas de 500).
