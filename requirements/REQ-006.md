# REQ-006 : Réservation valide

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un visiteur peut réserver une chambre sur des dates libres.

## Critères d'acceptation
1. Avec prénom, nom, email, téléphone et dates valides, la réservation est confirmée.
2. La réservation apparaît dans le calendrier admin.
3. La date de départ est postérieure à la date d'arrivée.
