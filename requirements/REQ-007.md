# REQ-007 : Réservation refusée

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Une réservation invalide ou en conflit est refusée avec un message clair.

## Critères d'acceptation
1. Avec des champs obligatoires vides ou un email invalide, la réservation est refusée.
2. Sur des dates déjà réservées pour la même chambre, la réservation est refusée.
3. Avec une date de départ avant la date d'arrivée, la réservation est refusée.
