# REQ-008 : Message de contact valide

- **Priorité** : Haute
- **Couche** : API + UI

## Description
Un visiteur peut envoyer un message via le formulaire de contact.

## Critères d'acceptation
1. Avec nom, email, téléphone, sujet et message valides, l'envoi réussit.
2. Une confirmation est affichée au visiteur.
