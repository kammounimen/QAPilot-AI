# REQ-009 : Message de contact refusé

- **Priorité** : Moyenne
- **Couche** : API + UI

## Description
Le formulaire de contact refuse les données invalides.

## Critères d'acceptation
1. Avec des champs vides, l'envoi est refusé et les erreurs sont affichées.
2. Avec un email invalide, l'envoi est refusé.
3. Avec un message ou un sujet trop court ou trop long, l'envoi est refusé.
