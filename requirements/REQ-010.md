# REQ-010 : Consultation des messages

- **Priorité** : Moyenne
- **Couche** : API + UI

## Description
Un administrateur connecté peut consulter les messages de contact reçus.

## Critères d'acceptation
1. Un message envoyé par un visiteur apparaît dans la boîte de messages admin.
2. L'administrateur peut ouvrir un message et lire son contenu.
3. L'administrateur peut supprimer ou marquer un message comme lu.
