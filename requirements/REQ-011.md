# REQ-011 : Déconnexion administrateur

- **Priorité** : Moyenne
- **Couche** : UI

## Description
Un administrateur connecté peut se déconnecter.

## Critères d'acceptation
1. Après déconnexion, l'espace admin n'est plus accessible sans nouvelle connexion.
2. Après déconnexion, le jeton n'est plus accepté par l'API.
