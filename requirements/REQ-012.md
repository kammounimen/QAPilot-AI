# REQ-012 : Endpoints protégés sans authentification

- **Priorité** : Haute
- **Couche** : API

## Description
Les actions réservées à l'administrateur sont refusées sans authentification valide.

## Critères d'acceptation
1. Créer, modifier ou supprimer une chambre sans jeton renvoie 401 ou 403.
2. Lire les messages sans jeton renvoie 401 ou 403.
3. Un jeton invalide ou expiré est refusé.
